# Burnkeys for the terminal

```
brew install claudewebsites/burnkeys/burnkeys
```

Then `burnkeys scan`, `burnkeys verify`, `burnkeys replace`, `burnkeys push`, `burnkeys mcp`.

Burnkeys finds every API key in your projects, checks each one with its provider, and swaps in new keys everywhere they live. It never prints a secret. The Mac app: https://burnkeys.com
